
The public keys are j-invariants of ideal classes, while the ideals themselves are private keys. The group action is the multiplication of ideals, and the shared secret is the ideal

$$
\large I_{s} = I_{A} \cdot I_{B}
$$

##### recovering tau

The `ideal_to_j` function converts the fractional ideal $I = \large \langle\alpha,\beta\rangle$ into its corresponding binary quadratic form. It uses the coefficients $\large A,B,C$ of the binary quadratic form to find the principal root $\large \tau$ in the upper half-plane:

$$
\large \tau = \frac{-B + \sqrt{ p } I}{2A}
$$

This $\large \tau$ defines the period lattice of the ideal, and the script computes it's j-invariant $\large j(\tau)$ via `elliptic_j(tau, prec=prec)`. 

By adding some debug prints to the function, we can tell that recoveirng $\large A$ and $\large B$ lets us recover the ideal basis:

```
I = Fractional ideal (331634390804810, 1/2*a + 615471438211751/2)
A,B = (331634390804810, -615471438211751)
```

The j-invariant is computed as:

```python
A = ZZ(alpha.norm() / NI)
B = ZZ(-(alpha * beta.galois_conjugate()).trace() / NI)
C = ZZ(beta.norm() / NI)

tau = (-CC(B) + CC.gen() * CC(-D).sqrt()) / (2 * CC(A))

return elliptic_j(tau, prec=prec)
```

Using the j-invariant, we can recover $\large \tau$ using the following function:

```python
def j_to_tau(j):
	tau = EllipticCurve(j=j).period_lattice().tau()
	return tau - floor(tau.real())
```

We recover $\large \tau$ up to a period ($\large j(\tau) = j(\tau+1)$), but can recover the "canonical" value by subtracting $\large 1$ if $\large \mathrm{Re}(\tau) >1$. However, with just $\large \tau$, we cannot recover $\large A,B$ since $\large p$ is also unknown.

##### recovering p

With $\large \tau$, we could easily recover $\large p$ 

$$
\large  \tau = \frac{-B + \sqrt{ p } I}{2A} = \frac{-1 + \sqrt{ p } I}{2}
$$

However, the given j-invariant is huge:

$$
\large pub_j = -3.1197712970\dots \times 10^{1100479732681975}
$$

Recovering $\large \tau$ via `EllipticCurve(j=j).period_lattice().tau()` is not feasible due to the size of $\large pub_{j}$, as pari will crash. Instead, we can observe that $\large pub_{j}$ increases with $\large p$:

```python
def check_j(A,B,p):
	tau = (-CC(B) + CC.gen() * CC(p).sqrt()) / (2 * CC(A))
	return elliptic_j(tau, prec=prec)
```

We can use a binary-search algorithm to determine what input $\large p$ gives $\large pub_{j}$:

```python
p = 0
ub = 2**100

		ub = p
	else:
```

##### Recovering the Ideals

With $\large p$ recovered, and the ability to recover $\large \tau$ for alice and bob, we can now recover $\large A,B$ to reconstruct each ideal:

$$
\large \tau = \frac{-B}{2A} + \frac{\sqrt{ p } I}{2A}
$$

We can take imaginary part of $\large \tau$ and solve:

$$
\large A = \frac{\sqrt{ p }}{2\mathrm{Im}(\tau)}
$$

And then:

$$
\large B = -2\cdot A\cdot\mathrm{Re}(\tau)
$$

with $\large A,B$, we simply reconstruct $\large \alpha,\beta$ to create the ideal:

```python
def j_to_ideal(p, tau):
	A = (p.sqrt() / (2*tau.imag())).round()
	B = (-2*A*tau.real()).round()
	K = QuadraticField(-p)
	beta = (-B + K(-p).sqrt()) / 2
	return K.ideal(A, beta)
```
